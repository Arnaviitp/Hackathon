# Hackathon

AI Legal assistant
Legal AI Assistant is a web platform where users can upload legal documents to receive instant plain-language summaries and ask questions about the content. Responses are generated by Google Cloud’s Gemini API, ensuring secure and reliable processing.

Features
1.Instant Understanding: Upload once, get clear summaries + answers.

2.Plain-Language Accuracy: Converts complex legal terms into simple, actionable text.

3.Secure & Scalable: Powered by Google Cloud Gemini for privacy + reliability.

🌏 Why It Matters

Growing demand for accessible legal services in India & globally.

No simple website offering instant legal document summaries.

Empowers users to understand legal documents without a lawyer.

🔑 Setup

Create a .env file in the project root:

GEMINI_API_KEY=your_api_key_here
Add .env to .gitignore:
.env

Load the API key in your code:
import 'dotenv/config';
const apiKey = process.env.GEMINI_API_KEY;


Run the app locally or deploy — it will securely use your API key.

Quick Flow
Upload a document.
Gemini API processes securely.
Get instant plain-language summary + Q&A answers.
